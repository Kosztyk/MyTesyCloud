# MyTESY Cloud v1.1.1

HACS-ready packaging with correct `custom_components/tesy` layout, MIT license recognition, updated documentation, and validated HACS/Hassfest workflows.

**Manual installation users:** replace the old `custom_components/tesy_cloud` directory with `custom_components/tesy` and restart Home Assistant. The integration's domain remains `tesy`.

No device-control, cloud request or MQTT logic was changed.
